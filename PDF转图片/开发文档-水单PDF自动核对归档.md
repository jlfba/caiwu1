# 水单 PDF 自动核对归档

## 目标

提供一个不依赖网页的 Windows 脚本。运行后依次选择报销/付款 PDF 文件夹和水单文件夹，按金额识别人民币与美元水单，自动将唯一匹配的一对文件归档。细小水单图片会先做三倍高质量放大、对比度与锐化增强再 OCR；控制台实时显示扫描数量、当前 OCR 文件、已识别金额、匹配和归档状态；日志中的金额统一为亮绿色加粗。

## 处理规则

- 来源 PDF：人民币读取“付款总额”或“汇款金额”右侧金额，以及“报销金额”“费用金额”“借款金额”“申请金额”表头右侧或下方金额；兼容 PDF 表格文字层分列顺序；美元读取“付款总额”。
- 人民币水单：识别同图内的 `金额` 字段与 `CNY` 金额（兼容 OCR 文字顺序颠倒）、`付款金额`、`金额（小写）`、`汇款金额`后的金额、`金额` 字段后（兼容多种横线和分行 OCR）的负数金额、微信/零钱通支付成功或支付宝交易成功页中央负数金额、`汇款金额小写` 后的金额；匹配结果放入 `水单正常匹配`。
- 美元水单 PDF：在水单目录的 `中信银行`、`招商银行` 子目录中，分别识别“现汇金额/购汇金额”及“交易金额”后的 `USD` 金额；匹配结果放入 `美金正常`。
- 水单按来源 PDF 的文件名重命名；同一金额出现多张候选水单时不移动，写入处理报告供人工核对。

## 输出与安全性

两个归档目录和 `水单匹配处理报告.csv` 均创建在所选的来源 PDF 文件夹中。文件仅在金额唯一匹配后才移动；目标已存在同名文件时自动保留两份文件，不会覆盖。

## 验证

1. 使用 `py_compile` 验证脚本语法。
2. 通过模拟文本的单元检查验证人民币三种金额规则、美元两种规则和负数金额规则。
3. 实际使用时先以少量可确认的 PDF/水单运行，检查 CSV 后再处理整批文件。
