# 专线利润报表追加脚本开发文档

## 本次修改：主单毛利公式续填

1. 加线、美线和欧线九张目标工作表均以“主单号”定位最后一条实际数据，读取该行“主单毛利”的公式。
2. 新增记录的“主单毛利”使用该公式的相对引用形式逐行填充；源预估报表中的同名列仍不读取。
3. 用当前报表验证新增行公式、金额计算和原有数据，更新版本记录后提交并推送本次提交。

## 目标

从用户自选的文件名含“预估报表”的工作簿的“汇总”工作表，按同名表头取值，追加到对应“利润报表”的“明细表”工作表。原工作簿只读，结果保存到各自利润报表所在目录的当天日期文件夹。

同一天重复运行时，每条线路在日期文件夹中仅保留一份最新结果；旧结果移入该文件夹的“历史版本”子目录。新结果写入成功后才切换，切换失败则恢复原结果。

## 文件与配对

1. 双击启动时只弹出系统 Excel 多选文件框；选中所需报表后立即合并，不再显示文件列表或“开始合并”窗口。取消选择则直接退出。
2. 文件选择结束后关闭隐藏窗口；处理完成使用前台置顶的系统提示框，用户点确定后打开结果文件夹。
3. 根据文件名中的“加”“美”“欧”及“预估报表”“利润报表”配对；每条线路允许多个预估报表，但只允许一个利润报表。
4. 加、美线仅处理源表名“汇总”和目标表名含“明细表”的组合。缺少工作表或无法配对时跳过并记录原因。命令行 --all 优先扫描原两个子目录；若已移走文件，则扫描当前报表根目录。

## 欧线扩展

1. 欧线预估报表与欧线利润报表按文件名配对；仅处理双方同名的美国空派、欧洲空派、欧洲卡航、欧洲海派、英国铁路、欧洲铁路、英国空派、英国卡航、英国海派九张工作表。
2. 欧线源表表头位于第 1 行，目标表头位于第 3 行。目标表大量空白格式行不算已有数据，按主单号列最后一条实际数据续接。
3. 每张表按同名列复制值与底色；额外复制双方同名的费用列及相关业务列。“主单毛利”不从源表复制，沿用目标表上一条实际数据的公式下拉。月份、周数下拉；应付-其他费用按服务商总应付减去其他应付列重算。
4. 英国空派目标表没有“应付-其他费用”，该列跳过并记录；目标保留原表结构。
5. 源表若有 #REF! 等 Excel 错误，按源数据保留并在日志中记录对应字段与数量。

## 数据规则

1. 源表首行、目标明细表前十行中定位表头；需要复制的列若有重复表头，取最左侧并记录。
2. 按主单号非空判断有效源数据行。目标同时检查已有主单号列和已用区域末行，确保追加不覆盖旧数据。
3. 除“主单毛利”外的 23 列按同名表头复制公式计算值及单元格底色；“主单毛利”在新增行沿用目标公式，源表没有的其他列留空。
4. 月份、周数沿用目标最后一行的相对引用公式；应付-其他费用等于服务商总应付减去目标表所有“应付-”列的合计（排除自身）。
5. 新增行沿用目标末行格式。结果用 Excel 保存，保护原工作簿的图表等复杂内容。

## 实施与验证

1. 写脚本及日志、系统文件多选入口和命令行入口。
2. 用模拟工作簿验证配对、缺列留空、公式、颜色、日期文件夹和原文件不变。
3. 对现有加线、美线报表运行，并核对追加行数、关键值、公式与颜色。
