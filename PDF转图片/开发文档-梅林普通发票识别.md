# 梅林普通发票识别开发记录

## 目标

为收款组邵梅琳新增“普通发票识别”类型，识别普通发票号码、开票日期、购买方名称、销售方名称、货物或应税劳务/服务名称明细和总金额，生成不含图片的 Excel。

## 实施步骤

1. 在邵梅琳第三层新增普通发票识别入口。
2. 复用普通发票基础字段识别，并单独提取服务名称表头下面的内容。
3. 按指定顺序生成七列表格。
4. 支持多选和拖入文件夹，完成后直接下载表格。
5. 完成 Python 检查、前端构建和本地提交。
