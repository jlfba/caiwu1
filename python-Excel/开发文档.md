# 多表合并透视工具 开发文档

## 一、需求说明

编写一个 Python 脚本，实现以下功能：

1. **粘贴多个表格**：运行后提示用户把要合并的 Excel 表格粘贴到终端（支持资源管理器多选后
   Ctrl+C，再到终端 Ctrl+V 多行粘贴，每行一个路径；也支持输入 `c` 从剪贴板直接读取全部路径），
   粘贴后回车确认。实现方式参考 `pdf-v-photo/pdf转图片.py` 的粘贴/剪贴板读取逻辑。
2. **表名与列名展示**：把全部表的名称合并去重后列出；再把全部列名合并去重后列出，供选择。
3. **选择列并追加合并**：用户选择要保留的列，回车后只取这些列的数据，按粘贴顺序追加合并；
   合并后在每行数据末尾新增一列「数据来源表」，记录该行数据来自哪个表。
4. **透视汇总**：合并完成后进行透视汇总，列名可选择自定义或固定：
   - **自定义模式**：把合并好的汇总表的全部列列出供选择（行标签列 + 求和数值列）。
   - **固定模式**：用以下列做透视：运单号、币种、求和项:运费、附加费2（如超围长重附加费）、
     附加费1（如偏远费）、附加费3（如超长重附加费）、报关费、合计金额。
5. **透视表去向**：透视表做好后提示选择：
   - **直接输出保存**：保存为新的 xlsx 文件；
   - **插入表格**：提示粘贴要插入的主表，把透视表作为新工作表插入该主表；
     然后输入透视表工作表名称，列出主表全部工作表供选择；
     在所选工作表中用「运单号」去透视表匹配「运费」，回填到主表最后一列，
     再在该列后面新增一列 = 透视表「运费」- 主表已有「运费」。

## 二、开发环境

- Python 3.x（Windows）
- openpyxl 3.1.5（Excel 读写）

## 三、实现思路

### 3.1 粘贴/读取表格路径

复用参考脚本的输入工具设计：

- `PATH_RE`：优先匹配引号包裹的路径（可含空格），否则匹配连续非空白；
- 预读缓冲 `_PUTBACK`：多行粘贴时非路径行先暂存，让下一个问题优先读取；
- `read_paths()`：读取第一行后继续读取后续路径行（Ctrl+V 多行粘贴），空行结束；
- `read_clipboard_paths()`：用 tkinter 读取剪贴板，兼容资源管理器多选复制形态。

本脚本在参考基础上增强：一行内若有多个路径（如 `"d:/a.xlsx" "d:/b.xlsx"` 或
`d:/a.xlsx d:/b.xlsx`）也会拆分，支持「多个表格一起粘贴」。

### 3.2 读取表格

- 用 `openpyxl.load_workbook(read_only=True, data_only=True)` 读取每个文件；
- 默认取第一个工作表，第一行为表头；空表头补「未命名列N」；
- 文件按绝对路径去重；显示名取文件名，同名不同目录时附加目录区分。

### 3.3 列选择与合并

- 全部列名按出现顺序合并去重并编号，支持 `1,3,5-7`、`all` 等选择格式；
- 按粘贴顺序逐表追加数据，只保留所选列；某表缺列时该列留空并提示；
- 每行末尾追加「数据来源表」列，值为该表显示名。

### 3.4 透视汇总

- 固定模式：行标签 = 运单号、币种；数值列 = 运费、附加费1/2/3、报关费、合计金额；
  支持列名已带「求和项:」前缀的情况；输出列名统一为「求和项:xxx」。
- 自定义模式：分别选择行标签列与求和数值列。
- 数值转数字：去掉千分位、货币符号、单位「元」，无法解析的按 0 计。

### 3.5 透视表去向

- 直接保存：默认输出 `透视汇总.xlsx`（已存在时自动加时间戳）。
- 插入主表：加载主表 → 新增透视表工作表（重名先删后建）→ 选工作表 →
  按「运单号」匹配透视表「运费」回填到最后一列（新列「透视表运费」），
  再新增「运费差异（透视-原表）」列 = 透视运费 - 主表原运费；
  运单号用规范化文本匹配（数字/字符串兼容），重复运单号取第一个匹配值。

## 四、测试

- 用 3 个模拟表格 + 1 个主表做全流程脚本化测试（mock input）：
  多行粘贴读取、列选择、追加合并、固定模式透视、插入主表、回填运费、差异计算。
- 已测试：透视求和正确、插入工作表正确、回填与差异列数值正确。
