# 多表合并透视工具 开发文档

## 一、需求说明

编写一个 Python 脚本，实现以下功能：

1. **粘贴多个表格**：运行后提示用户把要合并的 Excel 表格粘贴到终端（支持资源管理器多选后
   Ctrl+C，再到终端 Ctrl+V 多行粘贴，每行一个路径；也支持输入 `c` 从剪贴板直接读取全部路径），
   粘贴后回车确认。实现方式参考 `pdf-v-photo/pdf转图片.py` 的粘贴/剪贴板读取逻辑。
2. **表名与列名展示**：把全部表的名称合并去重后列出；再把全部列名合并去重后列出，供选择。
3. **选择列并追加合并**：用户选择要保留的列，回车后只取这些列的数据，按粘贴顺序追加合并；
   合并后在每行数据末尾新增一列「数据来源表」，记录该行数据来自哪个表。
4. **透视汇总**：合并完成后进行透视汇总，直接选择要求和的数值列，分组列自动取运单号/币种。
5. **透视表去向**：透视表做好后提示选择：
   - **直接输出保存**：保存为新的 xlsx 文件；
   - **插入表格**：提示粘贴要插入的主表，把透视表作为新工作表插入该主表；
     然后输入透视表工作表名称，列出主表全部工作表供选择；
     在所选工作表中用「运单号」去透视表匹配「运费」，回填到主表最后一列，
     再在该列后面新增一列 = 透视表「运费」- 主表已有「运费」。

## 二、开发环境

- Python 3.x（Windows）
- openpyxl 3.1.5（Excel 读写）

## 三、实现思路

### 3.1 粘贴/读取表格路径

复用参考脚本的输入工具设计：

- `PATH_RE`：优先匹配引号包裹的路径（可含空格），否则匹配连续非空白；
- 预读缓冲 `_PUTBACK`：多行粘贴时非路径行先暂存，让下一个问题优先读取；
- `read_paths()`：读取第一行后继续读取后续路径行（Ctrl+V 多行粘贴），空行结束；
- `read_clipboard_paths()`：用 tkinter 读取剪贴板，兼容资源管理器多选复制形态。

本脚本在参考基础上增强：一行内若有多个路径（如 `"d:/a.xlsx" "d:/b.xlsx"` 或
`d:/a.xlsx d:/b.xlsx`）也会拆分，支持「多个表格一起粘贴」。

### 3.2 工作表选择与表格读取

- 粘贴表格后**立即反馈**已识别的表格数量与名称，避免「读了没反应」的困惑。
- 逐一读取全部文件的**所有工作表名称**，合并去重后列出供用户选择；
- 用户选择后，全部表格统一用该**工作表名称**读取（而非按序号，避免各模板工作表位置不一的问题）；
- 列名默认取第 1 行；公式值为 `data_only=True`。

### 3.3 列选择与合并

- 全部列名按出现顺序合并去重并编号，支持 `1,3,5-7`、`all` 等选择格式；
- 选择后检查各表是否**缺少所选列**（精确匹配）；若有缺列则提示并询问是否重新选择；
- **列名替代映射**：选择后可指定某列的替代列名（可多个），合并时按「所选精确名 → 替代名精确 → 模糊包含」顺序匹配子表数据；
  改名提示支持直接输入列名或序号进入（不再只认 y/n）。
- 按粘贴顺序逐表追加数据，只保留所选列；某表缺列时该列留空并提示；
- **自动生成「汇总」列**：检测所选列中的费用列（运费/附加费1/2/3/报关费，子串匹配），
  自动计算每行合计金额，插在**最后一个费用列（通常是报关费）后面**；全部费用为空时汇总留空；
- 每行末尾追加「数据来源表」列，值为该表显示名。

### 3.4 透视汇总

- 透视步骤简化：不再选固定/自定义模式，直接选择**要求和的数值列**；
- 分组列（行标签）自动取「运单号、币种」（存在则用），否则取其余非求和列中除「数据来源表」外的列；
- 透视模式选择前先列出合并后汇总表的全部列，方便选求和列；
- 数值转数字：去掉千分位、货币符号、单位「元」，无法解析的按 0 计。
- 输出列名统一为「求和项:xxx」。

### 3.5 透视表去向与保存路径

- **保存路径支持拖入文件夹**：`read_save_path()` 自动去掉 Windows 拖入时带的引号，
  拖入文件夹则在文件夹下生成默认文件名；无扩展名时自动补 `.xlsx`。
  合并汇总表和透视表保存均使用该函数。
- 直接保存：默认输出 `合并汇总.xlsx` / `透视汇总.xlsx`（已存在时自动加时间戳）。
- 插入主表：加载主表 → 新增透视表工作表（重名先删后建）→ 选工作表 →
  按「运单号」匹配透视表「运费」回填到最后一列（新列「透视表运费」），
  再新增「运费差异（透视-原表）」列 = 透视运费 - 主表原运费；
  运单号用规范化文本匹配（数字/字符串兼容），重复运单号取第一个匹配值。

### 3.6 返回上一步（v1.2.0）

- 任意选择步骤输入 `b` / `back` / `上一步` / `返回` 触发 `GoBack` 异常；
- main 用步骤计数器 + `while True: try/except GoBack` 组织：`step` 递减后重入上一步骤，
  该步骤之前的输入全部保留，本步骤数据重新计算；
- `_ask_back()` 在 `_ask()` 基础上增加返回触发；各步骤的关键提示均改用 `_ask_back`。

### 3.7 列名统一（v1.3.0）

- 读表后、选列前，检测各表列名一致性：
  - **所有表都有的列**：所有表都有该列名；
  - **部分表才有的列**：只部分表有，提示缺哪些表；
- 可选一个表、改其中某列的列名，改完重新检测一致性，直到列名一致；
- 解决各表列名不一致（如 5月 有「运单号」、其他月只有「订单号」）；
- 改名直接修改内存中该表的表头，合并时按改名后的列名输出。

## 四、测试

- 用 3 个模拟表格 + 1 个主表做全流程脚本化测试（mock input）：
  多行粘贴读取、列选择、追加合并、固定模式透视、插入主表、回填运费、差异计算。
- 已测试：透视求和正确、插入工作表正确、回填与差异列数值正确。
- **v1.1.0 交互测试**：5 个真实物流商对账单（FBA 工作表，3000~4300 行/表）全流程验证：
  - 按名称选择工作表、列选择/重选/替代列名、自动汇总列、透视模式、保存路径拖入。
