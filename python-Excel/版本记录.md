# 多表合并透视工具 版本记录

## v1.4.0（2026-08-08）

- **透视步骤简化**：
  - 删除固定/自定义模式选择，直接自选求和列；
  - 删除「行标签列」选择步骤，分组列自动取「运单号、币种」（不存在则取其余非求和列、除数据来源表外的列）；
  - 只问「哪些列做求和计算」，透视自动完成。
- 移除已废弃的固定模式常量和 `resolve_columns` 函数。

## v1.3.5（2026-08-08）

- 列名统一每次改名后询问「1 继续改名 | 2 下一步（进入选列）」，回车默认继续，改完可直接进下一步。

## v1.3.4（2026-08-08）

- 列名统一支持**批量改名**：表可选多个（2 3 4 5 / 2-5）；
  批量改名用「新名=旧名」格式，一次改多列，空格或逗号分隔（如 `运单号=订单号 国家=Country`）。

## v1.3.3（2026-08-08）

- 列名统一入口改为 1/2 数字选择：有列名不一致时提示「1 进入列名统一 | 2 跳过」，回车默认进入；
  列名全部一致时自动跳过，不再误跳。

## v1.3.2（2026-08-08）

- 交互提示文字改为**加粗亮绿色**（ANSI 转义序列），与输出信息区分，更易看清；
  - Windows 控制台自动启用 VT 处理；非终端（重定向/管道）时自动关闭颜色，避免乱码。

## v1.3.1（2026-08-08）

- 简化「列名统一」步骤显示：表格用月份短名（5月/1月）替代超长文件名；
  一致列只显示前几个+总数；不一致列改为一行「只有 X 有，缺 Y」。

## v1.3.0（2026-08-08）

- **新增「列名统一」步骤**（读表后、选列前）：检测各表列名一致性，把列名分成
  「所有表都有的列」与「部分表才有的列」分开列出；
  - 可选择一个表、改其中某列的列名，改完重新检测一致性；
  - 直到列名一致后进入选列，解决「订单号 vs 运单号」这类各表列名不一致问题。
  - 已测试：5月(有运单号) + 1月(无运单号) → 检测出运单号仅5月有 → 改1月订单号→运单号 → 重新检测通过。

## v1.2.0（2026-08-08）

- **新增「返回上一步」**：任意选择步骤输入 `b` / `back` / `上一步` / `返回` 即可回到上一个步骤。
  - 实现：`GoBack` 异常 + `_ask_back()` + 步骤计数器（step 0=粘贴 / 1=选工作表 / 2=选列+合并 / 3=透视 / 4=透视保存/插入）。
  - 例如：选列时输 `b` → 回到选工作表；选透视模式时输 `b` → 回到选列/合并。
  - 已测试：真实对账单选列后输 b → 跳回工作表选择 → 重新选列合并透视全流程通过。
- **改名提示文字更清晰**：明确映射方向「汇总表列名 ← 子表里的实际列名」，
  提示改为「部分子表里的列名可能和汇总表列名不一致？」。

## v1.1.0（2026-08-08）

- **UX 优化**：
  - 粘贴/读取路径后立即打印「已识别 N 个表格」，不再跳到下一步才确认，解决「读了没反应」的困惑。
  - 合并表列名在透视模式选择前先列出，避免盲目输入序号；固定模式缺分组列时显示具体缺了哪个。
  - 删除了「请输入子表列名所在行」提问步骤，默认固定第 1 行为列名。
- **工作表选择改为按名称（合并去重）**：
  - 原按「序号」选工作表（各模板工作表顺序可能不一），改为识别全部文件的工作表名称、合并去重后列出供选择；
  - 选择后全部表都用该工作表名称读取。
- **保存路径支持拖入文件夹**：新增 `read_save_path()`，自动去掉 Windows 拖入时带的引号，拖入文件夹在其下生成默认文件名。
- **列选择增强 — 缺少列时重新选择 + 列名替代映射**：
  - 检测到部分表缺少所选列时，提示后询问是否重新选择列；
  - 新增「是否修改某个列的名称」步骤：可为所选列指定替代列名（多个），合并时按「所选名 → 替代名 → 模糊包含」顺序匹配子表数据；
  - 改名提示改为可直接输入列名/序号进入改名，不再只认 y/n 导致静默跳过。
- **合并时自动生成「汇总」列**：运费 + 附加费1 + 附加费2 + 附加费3 + 报关费，插在最后一个费用列（报关费）后面；全部费用为空的留空。
- **固定模式透视「合计金额」匹配增强**：alias 匹配 费用合计、合计、费用总计、汇总，不再因列名差异而跳过。
- **`read_table` 改为按工作表名称读取**：支持 `sheet_name` 参数，优先于 `sheet_idx`。

- 首个版本。
- 功能：
  - 支持一次粘贴多个 Excel 表格（Ctrl+V 多行粘贴 / 输入 c 从剪贴板读取 / 一行多路径），
    参考 `pdf-v-photo/pdf转图片.py` 的粘贴实现；
  - 表名合并去重、列名合并去重，选择要合并的列后按粘贴顺序追加合并；
  - 合并后每行末尾新增「数据来源表」列；
  - 透视汇总：固定模式（运单号、币种分组，对运费/附加费1/2/3、报关费、合计金额求和）
    与自定义模式（自选行标签列与求和数值列）；
  - 透视表去向：直接保存为 xlsx，或插入粘贴的主表中作为新工作表；
  - 插入主表后：按「运单号」回填透视表「运费」到最后一列，
    再新增「运费差异（透视-原表）」列 = 透视运费 - 主表原运费。
- 已测试：3 表合并 → 固定透视 → 插入主表 → 回填运费/差异列，验证通过。
