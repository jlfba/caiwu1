# 创时附加费字段坐标调整开发文档

## 目标

调整付款组“创时附加费”模式中 Invoice number 和 Reference 的提取坐标，保持 Description、Quantity、Price、Amount 的现有提取逻辑不变。

## 实施步骤

1. 读取样例 PDF 的文字层坐标并复现当前提取结果。
2. 确认 Invoice number 与 Reference 标签下一行的值坐标。
3. 仅为创时附加费传入专用坐标范围：Invoice number `x=350–450`，Reference `x=450–580`。
4. 使用样例 PDF 验证字段和明细，执行 Python 语法检查。
5. 清理测试输出并提交本地 Git 仓库。

## 验收标准

- Invoice number 能识别为 `INV-19525`。
- Reference 能识别为 `14/08/26DPD附加费`。
- 明细四列继续正常提取。
- 其他创时发票类型不受影响。
