# 创时清关费字段提取调整开发文档

## 目标

调整 `web` 付款组的“创时清关费”模式，使其从发票文字层按实际 PDF 坐标提取以下字段：Invoice number、Reference、Description、Quantity、Price、Amount。

## 实施步骤

1. 检查清关费识别函数及 Web 调用链，确认修改共享识别脚本后 Web 可复用。
2. 根据样例 PDF 的文字坐标确认明细表四列边界，使用 `Description`、`Quantity`、`Price`、`Amount` 表头定位。
3. 仅调整“创时清关费”模式的输出列名为六个目标字段；保持其他付款组发票类型行为不变。
4. 使用样例 PDF 执行识别，核对发票号、Reference、明细及数量/价格/金额。
5. 运行 Python 语法检查和必要的回归检查。
6. 更新版本记录，从当前版本递增一个修订版本，并提交本地 Git 仓库。

## 验收标准

- 样例 PDF 至少识别出第一页的 8 行明细。
- 清关费 Excel 列顺序为：Invoice number、Reference、Description、Quantity、Price、Amount。
- 数量、价格、金额分别来自 PDF 的 Quantity、Price、Amount 坐标列。
- 其他发票类型的提取逻辑不发生变化。
