# 收款组开票日期识别开发文档

## 需求目标

收款组处理增补“开票日期”字段，从中文发票中的“开票日期”标签识别日期，并在图片配套 Excel 字段中排在“发票号码”之前。

## 数据约定

- 输出字段顺序：开票日期、发票号码、购买方、销售方、金额。
- 日期统一规范为 `YYYY-MM-DD`，兼容 `YYYY年MM月DD日`、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`。
- 日期未识别时输出“未知”，不得影响其他字段识别和 Excel 生成。
- 重命名后的图片文件名携带开票日期，以便现有 Excel 插图流程复用同一数据源。

## 开发步骤

1. 扩展收款组 OCR 字段结构及开票日期提取规则。
2. 调整图片重命名字段顺序，开票日期置于发票号码之前。
3. 调整 Excel 字段解析及输出顺序，保持纵向、横向排版均正确。
4. 更新收款组页面说明及相关代码注释。
5. 增加版本记录。
6. 执行日期格式、未知值、文件名解析和 Excel 输出验证。
7. 将本次变更提交到本地 Git 仓库，不推送远程。

## 验收标准

- 示例“开票日期：2026年08月06日”输出为 `2026-08-06`。
- Excel 中“开票日期”位于“发票号码”前。
- 原有发票号码、购买方、销售方、金额字段保持可用。
- 无开票日期或识别失败的发票仍能生成结果，并显示“开票日期：未知”。
