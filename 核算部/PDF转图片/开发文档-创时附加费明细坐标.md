# 创时附加费明细坐标调整开发文档

## 目标

重新设置创时附加费明细表 Description、Quantity、Price、Amount 的坐标分界，Invoice number 和 Reference 保持现有专用坐标。

## 实施步骤

1. 复核样例 PDF 的明细数据坐标。
2. 为通用创时明细解析增加可选的明细列边界参数。
3. 仅为创时附加费设置边界：Description `<400`、Quantity `400–460`、Price `460–515`、Amount `>=515`。
4. 验证样例 PDF 的字段与明细，执行语法检查。
5. 更新版本记录并提交本地 Git 仓库。

## 验收标准

- Invoice number 和 Reference 继续正确提取。
- Description、Quantity、Price、Amount 分别写入对应列。
- 清关费、亚马逊卡派、正常卡派的明细坐标逻辑不变。
