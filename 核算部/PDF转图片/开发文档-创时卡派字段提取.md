# 创时卡派字段提取调整开发文档

## 目标

调整付款组“创时卡派”模式，按发票实际文字坐标提取 Invoice number、Reference、Description、Quantity、Price、Amount。

## 实施步骤

1. 检查 Web 调用链与共用识别脚本，确认创时卡派模式的入口和输出列。
2. 根据样例 PDF 坐标定位 Invoice number、Reference 及 Description、Quantity、Price、Amount。
3. 将创时卡派输出列名统一为六个目标字段，并使用卡派专用的发票头部坐标。
4. 使用样例 PDF 执行原识别函数和 Web 端 Excel 生成验证。
5. 执行 Python 语法检查，清理一次性测试输出。
6. 更新版本记录并提交本地 Git 仓库，不推送 GitHub。

## 验收标准

- Invoice number 为 `INV-19402`，Reference 为 `CSLU6336823 4票卡派（含临时燃油10%）`。
- 明细按 PDF 坐标提取 Quantity、Price、Amount，Description 内容合并为单列。
- Excel 列顺序为：Invoice number、Reference、Description、Quantity、Price、Amount。
- 其他发票类型的提取逻辑保持不变。
