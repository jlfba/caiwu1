# 创时卡派旧格式兼容修复开发文档

## 目标

修复 Web 端创时卡派导出时旧版 7 列识别结果与新版 6 列表头错位的问题，确保 Invoice number 和 Reference 写入正确列。

## 实施步骤

1. 复现样例 `Invoice INV-19402-卡派.pdf` 的底层识别与 Web 导出结果。
2. 在 Web 导出层兼容旧版 `[Invoice, Reference, Description, Description(1), Quantity, Price, Amount]` 数据。
3. 将旧版数据规范化为六列，并合并两个 Description 字段。
4. 重新生成样例 Excel，检查表头、Invoice number、Reference 和明细行。
5. 执行语法检查，清理测试输出并提交本地仓库。

## 验收标准

- Excel 列顺序为 Invoice number、Reference、Description、Quantity、Price、Amount。
- Invoice number 不再被截断，Reference 不再显示为“未知”。
- 新旧两种行格式均可正确写入六列结果。
