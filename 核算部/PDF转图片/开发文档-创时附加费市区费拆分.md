# 创时附加费市区费拆分开发文档

## 目标

将 Description 包含“市区费”的费用项目拆分为一行一个运单号；Quantity、Price、Amount 三列在该费用段内纵向合并。其他费用项目保持一项一行。

## 实施步骤

1. 复用现有 `_split_dpd_city_fee` 行拆分和 `_MERGE_UP` 合并标记机制。
2. 仅在创时附加费提取入口调用拆分逻辑。
3. 使用 `Invoice INV-19525-附加费.pdf` 验证市区费行数量、右侧三列合并区域及其他费用行。
4. 执行 Python 语法检查并提交本地仓库。

## 验收标准

- 含“市区费”的费用段不再把运单号放在一个 Description 单元格内。
- Quantity、Price、Amount 在市区费段纵向合并。
- 其他费用仍保持原有 6 条费用行结构。
