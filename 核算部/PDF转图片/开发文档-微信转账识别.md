# 微信转账识别开发记录

## 目标

为收款组赵淑华新增“微信”类型，识别微信转账凭证中的转账时间和顶部负数支付金额，生成带原凭证附图的 Excel。

## 实施步骤

1. 新增独立处理模式，避免复用发票字段识别逻辑。
2. 支持微信凭证 PDF、PNG、JPG、JPEG，以及拖入文件夹收集文件。
3. 将转账日期、时分秒、金额写入固定四列表格，并将对应图片嵌入最后一列。
4. 保持支付宝、货拉拉为未接入入口。
5. 完成 Python 语法检查、前端构建和 Git 本地提交。

## 版本记录

- 0.0.1：新增微信转账凭证识别与附图表格导出。
- 0.0.2：新增支付宝、货拉拉支付凭证识别与附图表格导出。
- 0.0.3：支付凭证金额列去除负号。
  - 支付宝金额定位在“交易成功”上方的负数金额。
  - 货拉拉金额定位在“货拉拉”上方的负数金额。
