# 收款组发票识别提速开发文档

## 目标

在不降低开票日期、发票号码、购买方、销售方和金额准确率的前提下，减少电子发票整页 OCR 带来的等待时间。

## 技术方案

1. 每页优先读取 PDF 原生文字层并提取五个字段。
2. 原生文字层字段完整时跳过 OCR。
3. 字段不完整时，根据缺失字段识别发票对应区域。
4. 局部识别后仍有缺失时，使用整页 OCR 兜底。
5. 网页端保持原图片渲染、重命名和 Excel 插图行为不变。
6. 限制并行 OCR 数量，减少 CPU 线程争抢。

## 开发步骤

1. 抽离统一的 OCR/文字层字段解析函数。
2. 新增 PDF 页面文字层字段提取。
3. 新增按缺失字段执行的局部 OCR。
4. 调整网页收款组处理流程，传递文字层初始结果。
5. 增加识别来源与耗时日志。
6. 更新版本记录。
7. 验证文字层快速路径、局部 OCR、整页兜底和 Excel 输出。
8. 删除一次性测试脚本并提交本地 Git。

## 验收标准

- 文字层完整的电子发票不调用 OCR。
- 文字层不完整时只补识别缺失字段，并保留整页兜底。
- 原有五字段、文件名和 Excel 输出格式不变。
- Python 语法、功能测试和前端构建通过。
