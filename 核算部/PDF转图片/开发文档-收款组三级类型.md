# 收款组三级类型开发文档

## 目标

将收款组调整为“小组 → 人员 → 类型”的三级选择结构。本次实现赵淑华的“发票识别、微信、支付宝、货拉拉”四个类型入口，其中发票识别可用，后三个类型先展示并标记为暂未接入。

## 实施步骤

1. 保留第一层收款组选择。
2. 保留第二层人员选择，并使赵淑华进入第三层类型选择。
3. 新增第三层“发票识别、微信、支付宝、货拉拉”选项；选中发票识别后沿用赵淑华原有 mode 2 处理流程。
4. 未选择第三层类型时禁止上传和制作，避免误提交。
5. 预留微信、支付宝、货拉拉的类型数据结构，但本次不启用未实现流程。
6. 运行前端构建和代码检查，完成本地 Git 提交，不推送 GitHub。

## 验收标准

- 收款组 → 赵淑华 → 发票识别可以正常进入上传和制作。
- 赵淑华未选择类型时不能提交。
- 现有赵淑华发票识别输出不变。
- 微信、支付宝、货拉拉暂不影响当前页面和处理逻辑。
