# 收款组人员模式调整开发文档

## 目标

将收款组的现有模式 1、模式 2 分别以谢莉丽、赵淑华命名；新增邵梅琳识别模式。

## 需求范围

1. 谢莉丽：保留原模式 1 的 PDF 转图片、发票识别、可插入模板表格与图片排版能力。
2. 赵淑华：保留原模式 2 的发票识别及含图片信息表格能力。
3. 邵梅琳：新增只识别、不保存或写入图片的流程；支持选择多个 PDF，以及将文件夹拖入上传区后收集其中的 PDF。
4. 邵梅琳输出 Excel 固定六列：开票日期、我方发票抬头（购买方信息）、对方发票抬（销售方信息）、发票号、摘要、金额。
5. 摘要提取发票项目名称下方的内容；完成识别后直接生成可下载的 Excel，不显示模板、插图或排版选项。

## 实施步骤

1. 完成现有收款组识别、任务队列、上传组件与页面条件渲染的基线检查。
2. 在界面中把原模式 1、模式 2 改为谢莉丽、赵淑华，并增加邵梅琳入口和对应说明。
3. 为上传组件加入可选的文件夹选择与拖放目录遍历；仅邵梅琳入口启用，递归收集 PDF 并保持原有去重逻辑。
4. 在 Python 识别层加入“摘要”提取：先使用 PDF 文字层，再对字段不足的页面执行 OCR 兜底。
5. 在后端任务分支中加入邵梅琳处理：每页输出一行六字段，调用通用 Excel 写入方法生成纯数据表。
6. 补充 README、版本记录，并运行后端语法检查、前端构建及针对字段/目录收集的验证。
7. 仅提交本次涉及文件到本地 Git 仓库；不推送 GitHub。

## 验收标准

- 收款组入口可清晰选择谢莉丽、赵淑华、邵梅琳。
- 谢莉丽与赵淑华保留各自原有输出能力。
- 邵梅琳可拖入文件夹或选择文件夹，自动加入其中 PDF。
- 邵梅琳结果表不含图片，表头及字段顺序完全符合需求。
- 处理完成后可直接下载 Excel。
