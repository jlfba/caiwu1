# 创时附加费 Description 归属修复开发文档

## 目标

修复多页创时附加费中费用名称、运单号和金额行的归属问题，确保每个费用项目的 Description 与对应 Quantity、Price、Amount 保持一致。

## 实施步骤

1. 按费用名称分段解析附加费明细，跨页延续当前费用段。
2. 将费用名称及其后续运单号合并到同一个费用 Description。
3. 去除分页造成的连续重复费用名称。
4. 保留原有 Invoice number、Reference 和金额坐标逻辑。
5. 验证样例 PDF、Web Excel 和 Python 语法。

## 验收标准

- 样例 5 页 PDF 输出 7 条费用明细。
- Description 以 `DPD 市区费`、`北爱清关费`、`重新贴面单费` 等费用名称开头。
- 金额保持 `35.10、7.00、154.80、198.00、7.75、3690.00、320.00`。
